# 智慧植栽澆水模擬系統 (NUCLEO-G474RE 期中專題)
透過 PA0 外接按鈕模擬土壤濕度下降，PA8 PWM 控制 LED 燈顯示當前濕度，當土壤過乾時自動觸發 PA9 模擬馬達澆水 5 秒並平滑恢復濕度。

## 1. 情境故事：誰、在哪、遇到什麼麻煩
- **對象與場景**：居家室內植物照顧者，平時外出工作無法即時觀察盆栽土壤濕度。
- **面臨痛點**：植物容易因為缺水枯萎，或是過度澆水導致爛根；需要一個自動化的濕度監測與澆水復原機制。

## 2. 替身對照：故事裡的模組 -> 板上替身
- **土壤濕度感測器** -> PA0 外接實體開關 (按按鈕模擬土壤水分流失)
- **土壤濕度指示燈 (A燈)** -> PA8 TIM1_CH1 PWM LED (亮度代表土壤濕度 100%~0%)
- **抽水馬達/水泵 (B燈)** -> PA9 GPIO Output LED (亮起代表馬達正在抽水)

## 3. 功能與驗收條件：動作、預期、實測結果
- **開機自檢**：電源開啟時 PA9 (B燈) 亮起 1 秒後熄滅，確認馬達周邊運作正常。
- **濕度遞減 (1~4 次按下)**：每次按下 PA0 按鈕，PA8 (A燈) PWM 佔空比依序降至 75% -> 50% -> 25% -> 10%，模擬土壤濕度下降。
- **自動澆水復原 (第 5 次按下)**：當濕度降至最低並再次按下時，PA8 熄滅、PA9 亮起 (馬達運作)；PA8 於 5 秒內由 0% 平滑漸亮恢復至 100%，隨後 PA9 熄滅並重置計數器。

## 4. 用到的技術：第 3 ~ 7 週勾選表
- ** GPIO 輸出**：PA9 控制馬達指示燈 (B燈)
- ** GPIO 輸入**：PA0 讀取外接按鈕 (開啟內部 Pull-up)
- ** 複用功能 AF**：PA8 設定為 Alternate Function (TIM1_CH1 PWM)
- ** PLL 170 MHz**：SystemClock_Config() 配置系統主時脈至 170 MHz
- ** 軟體去彈跳**：PA0 按鈕搭配 HAL_Delay(30) 消抖與 while 迴圈放開檢測
- ** PWM**：PA8 使用 TIM1_CH1 (PSC=169, ARR=999) 控制亮度變換與 5 秒漸亮復原

## 5. 腳位表：用到的每支腳與用途
- **PA0** = GPIO Input (Pull-up) | 外接實體按鈕 (按下接 GND)
- **PA8** = TIM1_CH1 PWM Output | 濕度指示燈 (A燈)
- **PA9** = GPIO Output (Push-Pull) | 馬達運作指示燈 (B燈)

## 6. 建置與執行：開發環境、燒錄步驟、終端機設定、命令
- **開發環境**：STM32CubeIDE v1.13.0 / STM32CubeMX
- **燒錄步驟**：
  1. 將 NUCLEO-G474RE 經由 USB 連接至電腦。
  2. 使用 STM32CubeIDE 開啟專案，點擊 `Run` 或 `Debug` (F11) 將韌體編譯並燒錄至晶片。
- **執行方式**：燒錄完成後自動執行；按下 PA0 按鈕可觀察 PA8 亮度變化與第 5 次的 PA9 澆水流程。

## 7. 程式結構：哪個檔案做什麼、ISR 與主迴圈分工
- **Core/Src/main.c**：包含系統時脈設定 `SystemClock_Config()`、周邊初始化 (`MX_GPIO_Init`, `MX_TIM1_Init`)，以及主迴圈 `while(1)` 中的按鈕輪詢、防手震、PWM CCR 暫存器修改與 5 秒平滑漸亮演算法。
- **主迴圈分工**：本專案採用 Polling 輪詢機制管理按鈕事件與時序，未啟用 EXTI 或 Timer ISR 中斷。

## 9. AI 使用說明：哪段請 AI、你怎麼查核
- **AI 輔助開發**：使用 AI 協助生成包含 HAL 庫周邊初始化 (`MX_TIM1_Init`, `MX_GPIO_Init`) 的 `main.c` 基底程式碼與 PWM 軟體 Fade-in 演算法。
- **查核與修復**：經實測驗證，發現 TIM1 高級定時器需補上 `__HAL_TIM_MOE_ENABLE()` 始能輸出波形，並修正了麵包板 GND 電源軌斷軌與 PA0 軟體消抖等待邏輯。

## 10. 已知限制：哪些用替身、換真貨要改哪裡
- **按鈕替身限制**：目前採用人工按鈕模擬水分自然蒸發與吸收，非真實環境連續變化。
- **換真貨調整**：若換成真實土壤濕度感測器，需將 PA0 改為 ADC 腳位 (如 PA0_ADC1_IN1) 讀取類比電壓；若換成真實 5V/12V 水泵，PA9 需外接繼電器 (Relay) 或 MOSFET 驅動模組，不可直接由 GPIO 驅動高電流負載。
