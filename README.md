#盆栽自動澆水器（ NUCLEO-G474RE 期中專題）
植物若缺水了 盆栽偵測到立刻澆水
##1.情境故事：現代人時常因為工作繁忙而忘記替植物澆水，於是就發想了這款自動澆水器，自動偵測土壤的溼度若太乾就澆水。
##2.版上替身： 土壤濕度 → 紅燈
藍燈亮 → 正在澆水
按鈕按一下 → 快進兩小時
##3.功能與驗收條件：一開始土壤濕入紅燈亮，按了按鈕五下之後快進10小時，土壤乾燥需要澆水，藍燈亮起表示盆栽正在澆水，紅燈由暗轉亮，五秒後藍燈熄滅，土壤回到濕潤狀態。
##4.用到的技術：第 3 ～ 7 週勾選表（同投影片)
##5.腳位表：用到的每支腳與用途
-PA0 = 按鈕、PA8 = 紅燈、PA9 = 藍燈
##6.建置與執行：開發使用STM32CubeMX和STM32CubeIDE 2.2.0，先設定腳位和輸入輸出，接著設定PWM和亮度頻率，皆設定完後即可開始燒錄
